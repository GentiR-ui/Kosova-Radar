# Tasks

> ORDER of work. Vertical slices: each task delivers working behaviour end to end (API + UI + tests),
> closes in one commit, and stays under ~400 changed lines. Split anything bigger.
> Format: `- [ ] T### — title — REQs — Definition of Done`. Check the box only when its DoD holds.
> "Owns" = the task whose DoD requires that REQ's acceptance tests to pass. "Contributes" = partial work whose
> acceptance tests may still fail until the owning task lands.
> Common DoD for every task: `scripts/verify.sh --quick` green; reviewer no HIGH/MEDIUM; security-reviewer too where marked 🔒.
